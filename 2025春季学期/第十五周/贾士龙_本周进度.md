  - 对AeroGen的语义控制向量进行增强，通过dgrl方法根据类别语义向量构建图结构进行语义增强。
  
  - 具体实现方法：
  
  - ##   总体构想：DGRL 控制增强模块嵌入 Diffusion 模型
  
       当前的输入：
  
       `eps = diffusion_model( ``    x=x_noisy, ``    timesteps=t, ``    context=cond_txt, ``    control=control,                # layout + 多模态` `    category_control=category_control,  # 类别嵌入` `    mask_control=mask_control          # 区域mask` `)`
  
    ------
  
       将 DCL 和 GKM 的能力整合为一个新的模块 `SemanticGraphControlEnhancer`，并在输入 `diffusion_model()` 前增强控制输入，尤其是 `category_control` 和 `control`。
  
    ------
  
  1. ##   构建 DCL 模块（region-level knowledge transfer）
  
     - 目标：利用 strong RoI features（正样本）增强 class-ambiguous 的类别嵌入。
     - 输入：
       - RoI features（来自 layout encoder 或 backbone）
       - 类别标签（positive / ambiguous）
     - 输出：
       - 增强后的类别控制向量 `category_control_enhanced`
  
        DCL 基于动态图卷积 GCN，节点间边权由皮尔逊相关系数动态更新。
  
     ------
  
  1. ##   构建 GKM 模块（class-level semantic mapping）
  
     - 目标：引入全局类别语义图，对类间关系建图传播。
     - 输入：
       - 分类器的权重 `M ∈ [C, D]` → 用作 semantic pool
       - 当前分类概率 P（由 RoI 分类器给出）
       - 类别之间先验图 `Gc = (Vc, Ec)`（可由 WordNet、ConceptNet 构造或手工设定）
     - 输出：
       - 类别嵌入增强向量 `category_control_gkm`
  
        GKM 最终输出：
  
    `F_E = P @ εM @ WGK  # 类别嵌入增强后的表征`
  
  1. ##   在调用 diffusion_model 前进行控制增强
  
    在调用 diffusion_model 前加上如下逻辑：
  
  1.  原始输入的类别控制 `category_control_raw = category_embedding(category_ids)`
  2. DCL 增强 RoI 之间的关系 `category_control_dcl = DCL_graph_enhancer(region_features, category_control_raw, proposal_labels)`
  3. GKM 加入全局类别语义图信息 `category_control_gkm = GKM_enhancer(category_control_dcl, class_probabilities, classifier_weight)`
  4. 控制信息整合（可选 concat 或 attention 融合） `final_category_control = category_control_gkm  # 或融合 layout、mask-control`
  5. 输入主扩散网络 `eps = diffusion_model( ``    x=x_noisy, ``    timesteps=t, ``    context=cond_txt, ``    control=control, ``    category_control=final_category_control, ``    mask_control=mask_control ``)`

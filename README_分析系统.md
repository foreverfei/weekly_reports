# 学生周报进度分析系统使用说明

## 系统概述

本系统旨在自动化分析学生周报，评估每个学生的工作量和研究进度，并提供个性化的指导建议。系统能够：

- 📊 自动解析和评估所有学生的周报内容
- 📈 追踪每个学生的进度趋势和工作模式
- 🚨 识别需要特别关注的学生
- 💡 生成个性化的指导建议
- 📋 提供综合的班级管理报告

## 文件结构

```
weekly_reports/
├── analyze_progress.py     # 主要分析引擎
├── generate_summary.py     # 快速总结生成器
├── analysis_results/       # 分析结果输出目录
│   ├── 综合分析报告.md     # 完整的分析报告
│   ├── 所有周报数据.json   # 原始解析数据
│   └── [学生姓名]_详细分析.json  # 每个学生的详细分析
└── README_分析系统.md      # 本说明文件
```

## 使用方法

### 1. 快速总结（推荐给导师日常使用）

```bash
python3 generate_summary.py
```

这会显示：
- 🚨 需要重点关注的学生（评分<60分）
- ✅ 表现优秀的学生（评分≥85分）  
- 📋 整体情况统计
- 🔔 个别学生预警提醒

### 2. 完整分析报告

```bash
python3 analyze_progress.py
```

这会生成详细的分析报告，包括：
- 所有学生的排名和评分
- 每个学生的详细分析（工作模式、问题模式、一致性分析）
- 个性化指导建议

### 3. 分析特定学生

```bash
python3 analyze_progress.py --student 李泽康
```

查看某个学生的详细进度分析。

## 评分体系

系统使用三个维度评估学生表现：

### 1. 工作量评分 (0-100分)
- **实验工作**: 每项15分，最高25分
- **算法开发**: 每项20分，最高30分  
- **文献阅读**: 每项8分，最高20分
- **论文撰写**: 每项12分，最高20分
- **内容质量**: 基于字符数，最高10分

### 2. 进度质量评分 (0-100分)
- **基础分**: 50分
- **下周计划**: 目标(+15分)、任务(+15分)、时间安排(+10分)
- **问题处理**: 分析(+10分)、解决方案(+15分)
- **个人反思**: +10分
- **寻求帮助**: +5分
- **内容详实度**: 最高+10分

### 3. 问题处理评分 (0-100分)
- **无问题**: 基础80分
- **有问题但有分析**: +25分
- **有解决方案**: +30分
- **寻求帮助**: +15分
- **处理详细度**: 最高+10分

## 预警机制

系统会自动识别以下情况并发出预警：

- 🔴 **严重预警**: 工作量<30分，连续3周无实质工作
- 🟡 **关注预警**: 工作量下降趋势，问题解决能力弱
- 📊 **数据异常**: 连续空白报告，报告质量差

## 指导建议生成逻辑

系统基于以下因素生成个性化建议：

1. **工作量分析**: 低于50分建议增加工作量
2. **规划质量**: 低于60分建议改善计划制定
3. **问题处理**: 低于60分建议改善问题分析能力
4. **工作模式**: 基于主要工作类型给出平衡建议
5. **一致性分析**: 波动较大时建议保持稳定
6. **趋势分析**: 基于最近表现给出调整建议

## 报告解读指南

### 综合评分理解
- **90-100分**: 优秀，可作为榜样
- **75-89分**: 良好，继续保持  
- **60-74分**: 一般，有改进空间
- **60分以下**: 需要重点关注和指导

### 关键指标含义
- **高产周数**: 工作量评分≥70分的周数
- **低活跃周数**: 工作量评分≤30分的周数  
- **问题解决率**: 有解决方案的问题周数/总问题周数
- **一致性**: 基于标准差衡量工作稳定性

## 定制化配置

可以通过修改 `analyze_progress.py` 中的评分参数来调整评价标准：

```python
# 工作量评分权重
EXPERIMENT_WEIGHT = 15    # 实验权重
ALGORITHM_WEIGHT = 20     # 算法开发权重
LITERATURE_WEIGHT = 8     # 文献阅读权重

# 预警阈值
LOW_WORK_THRESHOLD = 30   # 低工作量阈值
CONCERN_SCORE = 60        # 需要关注的综合评分
```

## 注意事项

1. **数据质量**: 分析质量依赖于周报的填写质量
2. **评分基准**: 评分标准可能需要根据实际情况调整
3. **个人差异**: 建议结合具体情况解读分析结果
4. **隐私保护**: 分析结果仅供教学管理使用

# 1.仿真

1. **环境搭建**
    - **选择仿真平台：** **ubuntu+ros+gazebo**、**PyBullet**。
    - **构建场景：** 在仿真器中导入机械臂的URDF模型、各种日常物体以及不同的桌面环境。
2. **数据生成流程**
    - **任务定义：** 编程定义一系列任务，如“抓取”、“放置”、“开门”、“推送”，为每个任务准备多个自然语言指令。
    - **重置与随机化：**
        - **场景随机化：** 每个数据采集周期开始时，随机化物体位置、颜色等。
    - **执行任务与数据记录:**
        
        根据任务设计规划机械臂的动作序列并执行。在机械臂执行动作的每一步仿真步骤中，同步记录当前时刻的语言指令、由摄像头图像构成的视觉观察、机器人状态（关节角度、末端位姿等）、以及执行的动作。通过循环执行`p.stepSimulation()`来推进仿真，并可以添加适当延时（如`time.sleep(1.0/240.0)`）来控制仿真实时性。（**PyBullet）**
        
    - **处理终止条件**
        
        当一个任务周期结束时，判断终止条件。这通常是任务成功（如红色积木被成功放入红色盒子）、任务失败（如物体掉落、超出步数限制）。

# 2.主从臂

**数据流：** 专家观察场景 -> 操控主臂 -> 从臂同步运动 -> 系统同步记录**视觉观察**和**关节动作**

### **硬件搭建**

- **必需组件：** 主从机械臂、摄像头（固定视角或眼在手）、校准系统（将主从臂工作空间对齐）、数据记录计算机。

### **软件流程**

- **建立通信：** 通过ROS建立主从臂之间的实时控制话题，设置记录的数据话题。
- **手眼校准：** 精确校准摄像头与机械臂的坐标变换关系。
- **实现映射算法：** 编写节点，将主臂的位置和姿态实时映射到从臂的关节空间。
- **同步记录：**
    - **图像数据：** 录制RGB或RGB-D视频流。
    - **动作数据：** 记录从臂的**关节角度**、**末端执行器位姿**、**夹爪开合状态**。
    - **任务标签：** 记录当前执行任务的自然语言描述（如“拿起方块”）。

### **数据采集流程**

- 使用 `rosbag record` 命令记录所需话题。例如：
    
    ```
    rosbag record -o demonstration1 /camera/color/image_raw /joint_states /language_command
    ```
    
- 发布语言指令：在开始演示之前，向 `/language_command` 话题发布当前任务的语言指令，使用 `rostopic pub` 命令：

```
rostopic pub /language_command std_msgs/String "data: '抓取红色的积木'"
```

- 专家演示一个任务（如“抓取红色的积木”）。

系统录制从任务开始到结束的整个轨迹，形成一条（视频序列， 动作序列， 语言指令）的长序列数据。

### 数据处理

1. 数据清洗：检查记录的数据，删除失败的演示（如抓取失败、机械臂卡住等）。
2. 数据转换：如果需要，将bag文件转换为更高效的格式（如HDF5）。每个演示保存为一个HDF5文件，内部包含图像序列、关节状态序列、控制指令序列和语言指令。
3. 数据标注：确保每个演示都对应一个语言指令，并可能添加额外的元数据（如任务类型、成功与否等）。

### 自动化脚本

- 一个启动脚本，同时启动所有必要的节点和rosbag记录。
- 一个发布语言指令的节点，并与记录开始同步。
- 将bag文件转换为HDF5的脚本。

# 3.vr

1. **硬件搭建**
    - **VR头显**
    - **VR手柄：** 用于控制机械臂。
    - **PC：** 运行高性能的仿真引擎。
2. **软件流程**
    - **虚拟环境构建：** 在Unity中构建与目标实物环境一致的虚拟场景。
    - **交互设计：**
        - **直接控制：** 将VR手柄与机械臂的夹爪绑定，用户移动手柄就直接移动夹爪。系统自动解算出机械臂各个关节的角度。
        - **界面与反馈：** 提供虚拟的机器人模型和场景，并可以加入振动等触觉反馈。
    - **数据记录：** 原理与仿真环境类似，记录虚拟摄像头的图像、机械臂的关节状态/动作序列、以及语言指令。
3. **数据采集流程**
    - 专家佩戴VR设备，进入虚拟场景。
    - 他看到的是虚拟机械臂和任务场景。
    - 他用手柄控制机械臂完成“抓取杯子”等任务。
    - 系统在后台记录下**他所看到的画面**和**他发出的控制指令**。

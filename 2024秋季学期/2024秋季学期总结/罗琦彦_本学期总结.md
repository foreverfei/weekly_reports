## 重点论文
起初，进行了一体化图像修复领域的了解，阅读了关于一体化图像修复领域和图像修复领域的综述，针对综述中提出的多任务冲突，顺序学习及灾难性遗忘问题进行探究，发现强化学习可以应用于图像修复领域，由于强化学习的步骤性和可解释性，根据奖励函数可以调节强化学习在不同退化任务中的侧重比重，可以用于解决多任务冲突的问题，由于相关研究多停留在23年以前且并未查找到相关综述的整理描述，目前考虑将强化学习应用于图像修复领域作为主要研究方向。  
### 一体化图像修复
1.《A Survey on All-in-One Image Restoration: Taxonomy, Evaluation and Future Trends》介绍了一体化图像修复的原理，ALL-in-One方面目前的各个模型的优缺点，数据集整合，学习策略【**顺序学习，对比学习，多任务学习**】，当下的挑战【任务冲突，高质量数据集获取】和研究方向。  
2.《PromptIR: Prompting for All-in-One Image Restoration》，了解PromptIR的创新之处在于添加了Prompt模块（PGM+PIM）引入prompt来进行多种退化类型的整合修复工作，模型的缺点及改进方向。  
### 顺序学习
《Towards Effective Multiple-in-One Image Restoration: A Sequential and Prompt Learning Strategy》 提出两种策略：1.顺序学习【按顺序逐个学习IR任务】 2.prompt learning【帮助网络理解具体的任务，提高泛化能力】  
《Review Learning: Advancing All-in-One Ultra-High-Definition Image Restoration Training Method》review learning 算法【从上一次数据集中抽出偏离平均值的挑战性样本再加入这次数据集中】
### 强化学习图像修复
1.《Crafting a Toolchain for Image Restoration by Deep Reinforcement Learning》首次将强化学习应用到图像修复领域，将图像修复拆解为各个工具，利用强化学习从工具链中选出当下最合适的修复工具并根据奖励函数得到奖励。  
2.《PixelRL: Fully Convolutional Network With Reinforcement Learning for Image Processing》逐像素代理+采用FCN使得所有代理共享参数+Reward map convolution利用卷积将奖励传递至附近像素。  
3.《Path-Restore: Learning Network Path Selection for Image Restoration》Path-Restore由多路径CNN和一个pathfinder组成。多路径CNN提供了几条路径来解决不同类型的失真，通过路径查找器【加入强化学习】能够找到有效恢复每个区域的最佳路径。   
4.《Image Quality Assessment–driven Reinforcement Learning for Mixed Distorted Image Restoration》工具箱策略+通过RL代理捕获失真偏好以选择最佳恢复工具+多种质量评价方法BIQA改进奖励函数。
5.《RL-SeqISP: Reinforcement Learning-Based Sequential Optimization for Image Signal Processing》1.将ISP过程视为顺序学习过程，提出一种基于RL的顺序ISP参数整定模型。2.动态参数优化模块（即DPOM），通过当前参数和下游任务的反馈性能指导参数优化 。  
6.《STAR-RL: Spatial-Temporal Hierarchical Reinforcement Learning for Interpretable Pathology Image Super-Resolution》强化学习【增加可解释性并减少伪影】+分层思想【避免计算量的平均化，在非平坦且细节较多的区域分配更多计算】+多种质量评估指标【PSNR,SSIM,GMSD,FSIM{评估局部细节}】两级分层机制，在块级恢复LR图像，而不是整个图像。

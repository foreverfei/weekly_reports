# 本学期科研的主要进展

本学期的主要是前期调研学习，后面写了一个图像分类相关论文。


首先是阅读有关图像恢复与增强的论文：

1. 《Priors in Deep Image Restoration and Enhancement: A Survey》概括了深度学习在图像复原和增强中的应用，特别是先验知识的作用，为该领域提供了全面的概述和未来研究方向。创新点在于系统性地分析了先验的不同类型及其在图像处理任务中的重要性。

2. 《PromptIR: Prompting for All-in-One Blind Image Restoration》这篇论文提出了一种新的盲图像复原方法，称为PromptIR。该方法的创新之处在于引入了提示学习（prompting）的概念，通过在训练过程中加入退化类型和程度的提示信息，使得单一模型能够适应多种退化情况。这种方法不仅提高了图像复原的准确性和效率，还增强了模型对不同退化类型的泛化能力。此外，PromptIR还简化了图像复原流程，因为它不需要针对每种退化类型训练单独的模型。

3. 《Ingredient-oriented Multi-Degradation Learning for Image Restoration》这篇论文主要探讨了一种面向成分的多退化学习框架，用于图像复原任务。该方法的创新点在于它能够处理不同类型的图像退化问题，如去噪、去模糊和去雾等，并且通过使用提示学习的方法来动态指导恢复网络，从而有效地从各种类型和程度的退化中恢复图像。

4. 《A Survey on All-in-One Image Restoration :Taxonomy, Evaluation and Future Trends》这篇论文主要探讨了一体化图像复原的分类、评估和未来趋势。论文的创新点在于它首次全面回顾了一体化图像复原方法，探索其在多种退化场景下的应用与挑战，并通过整合先进的深度学习技术，不仅提高了恢复效果，还显著提升了模型的灵活性和通用性。

5. 《Prompt-based Ingredient-Oriented All-in-One Image Restoration》主要探讨了一种基于提示学习的一体化图像复原方法，该方法能够有效地从各种类型和级别的退化中恢复图像。利用提示来编码退化特定信息，从而适应各种退化类型。此外，该方法提供了一个通用且高效的插件模块，只需少量轻量级提示即可用于恢复各种类型和级别的受损图像，无需事先了解图像中存在的退化信息。这种方法允许模型泛化到不同的退化类型和程度，同时仍然在图像复原任务上取得最先进的结果。

   

还了解深度学习和CV的基本介绍以及发展历史，搞清了人工智能、机器学习、DL之间的关系。简单了解了Transformer，包括他的一些重要组成部分和特点、结构。学习了一下python基本语法



对PID进行了简单调研，了解了PID的基本概念和实现流程，优化PID算法在温湿度控制系统中的性能可以从调整PID算法的*权重系数*，加入*预测*功能，使用*模糊PID算法*入手。

了解了模糊控制器的原理：

1. 《Decoupling Fuzzy-Neural Temperature and Humidity Control in HVAC Systems》这篇论文主要探讨了一种基于解耦合模糊神经网络的温度和湿度控制方法，该方法适用于供暖、通风和空调系统。提出了一种新型的解耦合模糊神经PID控制器，该控制器具有自调整参数，能够更好地适应HVAC非线性系统。

2. 《Development of a new control method for the dynamic liquid desiccant dehumidification process》探讨了一种新的控制方法，用于动态液体干燥剂除湿过程。开发了一种结合PID控制和新型模糊逻辑控制（FLC）的新控制方法，该方法通过命令跟踪实验和抗扰实验验证了其可行性，为实现多参数、时变、非线性动态过程的大延迟动态控制提供了良好的参考。

   

后面主要是进行管材分类的任务：首先对数据进行收集与处理，都转换为相同的32×32，并进行了数据预处理，归一化，将标签转换为独热编码，从图像数据中减去平均值，实现均值中心化。

阅读了图像分类相关论文：

1. 《Residual Attention Network for Image Classiﬁcation》提出了一种结合残差网络和注意力机制的新型神经网络结构，用于提升图像分类任务的性能。
2. 《Evolving Deep Convolutional Neural Networks for Image Classification》提出了一种使用遗传算法的新方法来进化深度卷积神经网络的架构和连接权重初始化值，以解决图像分类问题。采用了一种高效的可变长基因编码策略，该策略能够代表多种网络块和网络深度。
3. 《Research on image classification model based on deep convolution neural network》主要探讨了基于深度卷积神经网络（CNN）的图像分类模型。论文的创新点在于提出了一种高效的方法来利用CNN提高图像分类系统的性能。
4. 《A survey of image classiﬁcation methods and techniques for improving classiﬁcation performance》回顾了图像分类方法和提高分类性能的技术，讨论了当前的图像分类技术、存在的问题以及分类性能提升的前景，重点介绍了用于提高分类准确性的高级分类技术，并讨论了与分类性能相关的一些重要问题。
5. 《Multimodal semi-supervised learning for image classification》提出了一种多模态半监督学习方法用于图像分类，先用有标签图像的图像内容和关键词训练MKL分类器预测无标签图像标签，再用有标签数据和分类器输出训练仅用视觉特征的分类器，实验表明该方法能提高分类性能。

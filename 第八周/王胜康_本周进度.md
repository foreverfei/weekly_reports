N_k^i] 和 [A_k^j] 被定义为**独立的 Parameter 参数**

1. **Token 化与位置记录:**
   - 将完整的文本提示，例如 [SOS], [N_l], [A_l], detailed, object, with, defects, [EOS]，转换成 Token ID 序列。
   - 在转换过程中，**记录**下特殊标记 [N_l] 和 [A_l] 在这个序列中的**位置索引**（例如，假设它们分别在索引 1 和 2 的位置）。
   - 对于这些特殊标记，可以使用一个预留的、不会在原始词汇表中使用的占位符 ID，或者就用它们在原始序列中的普通词 ID（如果词汇表里恰好有类似 "[N" 或 "[A" 的 token），但关键是记住它们的位置。
2. **编码普通词汇:**
   - 将包含占位符 ID（或其他临时 ID）的**整个 Token ID 序列**输入到**原始的、冻结的 CLIP 文本编码器的嵌入层 (nn.Embedding)**。
   - 这一步会为所有的 Token ID（包括占位符）查找对应的嵌入向量。普通单词（如 detailed, object）会得到它们预训练好的向量。占位符 ID 会得到一个对应的（通常无意义或可忽略的）向量。
   - **输出:** 得到一个初步的嵌入矩阵 
3. **嵌入可学习参数 ([N] 和 [A]):**
   - 现在，根据第 1 步记录的位置索引（例如索引 1 和 2）。
   - 使用**独立定义**的、**可学习的 Parameter 向量**覆盖/替换掉原来在这些位置上的占位符嵌入向量。
   - **输出:** 得到最终的、准备送入 Transformer 第一层的嵌入矩阵。

- 文献阅读：
  - 《FiLo: Zero-Shot Anomaly Detection by Fine-Grained Description and High-Quality Localization》精读
  - FiLo 包含两个关键组件：细粒度描述 (FG-Des) 和高质量定位 (HQ-Loc)。 FG-Des 利用大型语言模型 ( LLMs ) 为每个对象类别生成详细的异常描述，从而提高异常检测的准确性和可解释性。 HQ-Loc 通过结合使用 Grounding DINO 的初步定位、位置增强文本提示和多尺度多形状跨模式交互 (MMCI) 模块来改进定位，从而可以对各种尺寸和形状进行精确的异常检测。
  - 首先，通过LLM生成每个类别可能存在的细粒度异常类型列表，将这些描述填入可学习的文本模板中，获取表示“正常”和“异常”语义的文本特征。然后，将待检测图像和细粒度异常描述输入Grounding DINO，获得初步的异常定位框，并将位置信息添加到文本特征中。接着，将待检测图像输入CLIP图像编码器提取中间层特征，这些特征通过MMCI模块与包含位置信息的文本特征交互，生成异常分数图。最后，综合各中间层的异常分数图，得到最终的异常图和全局异常得分。

# 1.本学期工作总结

本学期主要是  

1）学习了一些一体化图像恢复的方法，了解下这一方向最近的发展情况以及未来趋势；

* All-In-One Image Restoration for Unknown Corruption

  设计了基于对比学习的退化特征编码器和退化特征引导的恢复网络，其可能是最早的一体化图像恢复的方法之一。

* PromptIR: Prompting for All-in-One Blind Image Restoration

  提出了一种基于提示学习的全能图像复原方法（**PromptIR**），该方法能够有效地从各种类型和程度的退化中复原图像。具体而言，该方法通过提示编码退化特定的信息，并利用这些提示动态引导复原网络。

* Restore Anything with Masks: Leveraging Mask Image Modeling for Blind All-in-One Image Restoration

  在于从损坏图像中提取常见信息，学习到图像本身内容，而非重点区分退化模式，有助于在考虑更多退化类型时实现平衡和强大的性能；旨在找到可以有效克服训练数据与推理数据之间分布偏移的关键层。

* A Survey on All-in-One Image Restoration: Taxonomy, Evaluation and Future Trends

  调研一体化恢复方向近些年的发展现状以及趋势

2）收集了不同退化的无人机数据集，先用一些方法在这些数据集做了下实验，其中低光数据集还是一般场景下的；

* **UAV-Rain1k**: A Benchmark for Raindrop Removal from UAV Aerial Imagery（雨水）
* **HazyDet**: Open-source Benchmark for Drone-View Object Detection with Depth-cues in Hazy Scenes（雾霾）
* Improving Aerial Instance Segmentation in the Dark with Self-Supervised Low Light Enhancement（**提出利用iSaid用CycleGAN合成低光数据集**）
* R2RNet: Low-light image enhancement via Real-low to Real-normal Network（LSRW）

* Restoration Algorithm of Blurred UAV Aerial Image Based on Generative Adversarial Network（使用**GoPro**的大部分进行训练，剩下的GoPro数据集、Kohler和自己飞的数据集作为测试集）

3）阅读针对单一退化的图像恢复方法，熟悉不同退化的特点以及恢复中需要注意的地方；

* Zero-Reference Deep Curve Estimation for Low-Light Image Enhancement

  该论文提出了**Zero-Reference Deep Curve Estimation (Zero-DCE)**，一种用于低光图像增强的创新方法，将低光照图像增强任务重新定义为**图像特定的曲线估计问题**，而不是传统的图像到图像映射。另外，该方法不需要任何成对或非成对的参考图像进行训练，而是通过一组**无参考损失函数**来驱动网络学习

4）整理收集无人机图像的退化特点，尝试根据最新论文中方法合成自定义的无人机退化数据集。

* OneRestore: A Universal Restoration Framework for Composite Degradation

  该论文提出了一种通用的退化合成模型，用以模拟复杂的复合退化场景，包括低光、雾霾、雨、雪等常见的图像退化现象。通过逐步叠加退化因素，模型能够生成逼真的复合退化图像，用于训练和评估图像恢复方法。

* MegaDepth: Learning Single-View Depth Prediction from Internet Photos

  提出了一个基于互联网照片的大规模深度数据集MegaDepth，利用其所提方法可以生成深度图。

* DesnowNet: Context-Aware Deep Network for Snow Removal

  论文提出了一种多阶段的深度网络DesnowNet，用于处理透明和不透明的雪花。该网络通过多尺度设计来建模雪花的多样性，并分别估计雪花掩码和色差图，以恢复被雪花遮挡的图像细节。其中，提供了用于合成雪花退化的雪罩图。

# 本学期科研的主要进展

科研的主要进展可以总结为对一个领域的接触和了解，主要是调研，论文阅读以及少量的源码阅读。
我有部分图形学知识，并且最新的基于机器学习的三维重建方法与cv/人工智能也有关系，所以尝试在这方面进行探索。


首先是了解是对该领域使用的基础方法的了解，阅读基于机器学习的三维重建方法的论文

1. 《NeRF-Neural Radiance Fields》该论文首次在基于神经网络的三维重建中取得了重大突破，使用一个MLP来建模场景，并利用简单图形学知识进行渲染
2. 《NeRF-Neural Radiance Fields》该论文对于这个领域的贡献是，首次将球谐函数用到三维重建中，实现了同一个点不同视角下的颜色表达，并可微，能够使用机器学习方法训练
3. 《3D Gaussian Splatting for Real-Time Radiance Field Rendering》该论文是基于机器学习的三维重建的新标杆，将3D高斯作为基础渲染元素，即实现了可微（能用机器学习方法进行训练）又实现了利用显卡的并行能力进行高效渲染，我之后的工作将以此论文为核心。此论文相对而言，涉及到的内容更多并且更复杂，在深入学习该论文的过程中花了不少时间。
4. 《2D Gaussian Splatting for Geometrically Accurate Radiance Fields》则是分析了3DGS的几个缺陷，并针对缺陷提出了改进方法，结果的某些方面优于3DGS方法，并且该方法得到的场景转为Mesh的效果远远优于3DGS。



之后考虑利用3DGS的真实渲染结果，调研是否可以替代cv、机器人、自动驾驶的训练数据，减少训练数据的处理成本。调研过程中，进行了3DGS算法的代码运行和场景训练，学习了解了机器学习代码结果复现的基本流程。调研多篇具身智能机器人训练数据构造的论文，对具身智能机器人领域的训练数据来源和形式有了基本了解。此次调研的结果是，3DGS只能用作基于静态场景的训练数据，例如场景理解、导航任务的训练数据。对于基于动态场景的训练，例如指定机器人完成移动某样物体的任务，3DGS无法满足，需要找到方法将3DGS场景转为传统的Mesh场景。



对3DGS场景转为传统Mesh场景的方法进行了简单调研。

1. 《SuGaR: Surface-Aligned Gaussian Splatting for Efficient 3D Mesh Reconstruction and High-Quality Mesh Rendering》论文提出了一种将3DGS场景转为Mesh的方法，并且可以对Mesh场景进行动画的制作。但实际效果相当有限。
2. 《2D Gaussian Splatting for Geometrically Accurate Radiance Fields》支持将3DGS场景转为传统点云场景，但我个人做实验得到的结果相当差，并且场景渲染效率很低。考虑是超参数的问题



未来的主要工作集中于将3DGS与传统cv/人工智能/自动驾驶等领域的结合应用，对该方面进行了论文调研

1. 《LangSplat: 3D Language Gaussian Splatting》论文实现了一种3D高斯语言场，将语义向量嵌入到了场景中，对当前渲染画面实现了开放词汇查询与语义分割。是3DGS与NLP领域结合的应用
2. 《LetsGo: Large-Scale Garage Modeling and Rendering via LiDAR-Assisted Gaussian Primitives》该论文实现了在轻量级设备上渲染大型场景，将渲染技术中的LoD技术应用到了3DGS中。
3. 《GS-SLAM: Dense Visual SLAM with 3D Gaussian Splatting》论文实现了3DGS与SLAM结合，实现了给定图像序列，绘制场景地图与跟踪相机位姿。但是该论文需要进一步的研究，里面很多内容感觉讲的不是很清楚，源码也没完全给出来。



因为之后的工作应该都是基于3DGS的扩展与修改，所以阅读3DGS的源码相当重要，当前阅读了部分3DGS的源码。

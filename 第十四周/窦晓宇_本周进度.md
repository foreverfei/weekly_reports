* 文献阅读：

  * 阅读了《Large Language Model Guided Progressive Feature Alignment for Multimodal UAV Object Detection》试图解决多模态无人机（UAV）目标检测中存在的语义和空间错位问题。具体来说，论文指出现有的多模态UAV目标检测方法往往忽视了不同模态之间语义差异的影响，这使得实现准确的语义和空间对齐变得困难，从而限制了检测性能。

  * 《OGMN_ Occlusion-guided Multi-task Network for Object Detection in UAV Images》提出了一种名为OGMN（Occlusion-guided Multi-task Network）的遮挡引导多任务网络来应对图片遮挡。 

  *   OGMN包含三个关键技术：

      1.遮挡估计模块（Occlusion Estimation Module, OEM）：用于定位UAV图像中的遮挡，并为遮挡引导输出遮挡定位结果。

      2.遮挡解耦检测头（Occlusion Decoupling Head, ODH）：替代通用的检测头，用于解决特征混淆问题，这是两个任务解码器之间的一种交互引导方式。 

      3.两阶段渐进优化过程（Two-phase Progressive refinement Process, TPP）：根据局部聚集特性在检测过程中设计，是另一种交互引导方式，用于优化检测过程。

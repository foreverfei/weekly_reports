- 文献阅读：
  
  - 《**Multimodal Industrial Anomaly Detection by Crossmodal Feature Mapping**》
  
    这篇论文（Costanzino 等人）提出了“**跨模态特征映射**”。
  
    1. **特征提取**：使用强大的、预训练好且**冻结**（不更新权重）的 Transformer 网络（2D 用 DINO，3D 用 Point-MAE）分别从图像和点云中提取特征。
    2. **学习映射关系**：训练两个**独立**的、**轻量级**的神经网络（MLP），用于学习**不同模态特征空间之间的映射关系**。一个网络学习根据 2D 特征预测对应的 3D 特征，另一个则根据 3D 特征预测对应的 2D 特征。
    3. **仅用正常样本训练**：关键在于，这两个映射网络**只在正常的、无缺陷的样本上进行训练**。因此，它们学会的是“好产品”上视觉外观和 3D 结构之间通常存在的关联模式。
    4. **检测异常**：在推理时，通过比较**实际提取到的特征**和**映射网络预测出的特征**之间的**差异**（论文中先用余弦距离训练，聚合时用了欧氏距离）来检测异常。如果观察到的 2D/3D 关系与模型学到的正常关系不符，就会被标记为异常。
    5. **结果聚合**：论文巧妙地将两个方向（2D->3D 和 3D->2D）的差异得分图通过**像素级“乘积”\**的方式结合起来。这有点像逻辑上的“与”操作，只有当\**两个模态都认为存在不一致**时，最终的异常得分才会高，这有助于减少误报。
  
    **主要亮点和成果：**
  
    - **性能优异**：在 MVTec 3D-AD 数据集上的结果非常亮眼。该方法在检测和分割任务上都达到了 SOTA（当前最佳）水平，甚至在一些指标上（尤其是在更严格的评估标准下，如 AUPRO@1%）略微超过了复杂的 M3DM 方法。
    - **效率高**：这是该方法的一大优势。因为它避免了使用内存库，所以推理速度**显著更快**（论文中报告约 21.7 fps 对比 M3DM 的约 0.5 fps），并且内存占用**大大降低**（约 438 MB 对比 M3DM 的 6.5 GB）。
    - **层剪枝技术**：他们还展示了一种对冻结特征提取器的层进行剪枝的技术，能创建更小、更快的模型版本（称为 Ours-S、Ours-T）。值得注意的是，“Ours-S”在仅使用其完整模型不到一半内存的情况下，仍然达到了 SOTA 性能；而“Ours-T”运行速度极快（约 42.8 fps），性能依然优于之前的 BTF 和 AST。
    - **少样本能力强**：即使只用很少的正常样本（5个、10个或50个）进行训练，该方法也表现得非常好，在少样本（Few-Shot）设置下同样达到 SOTA。这对于工业界来说非常实用，因为收集大量完好样本有时很困难。
